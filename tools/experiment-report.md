# 中文推理占比实验：仅 AGENTS.md vs 插件注入

> 状态：已完成（2026-11-04，DSH desktop 0.2.1-rc.5）
> 目的：按计划做 A/B 对照，但把「方案 A（覆盖 `system-prompt` config 加 `personaSuffix`）」换成「只靠 `~/.dsh/AGENTS.md`」。

## 实验设计

| 项 | 内容 |
|---|---|
| 宿主 | 当前运行中的 DSH desktop 0.2.1-rc.5（同一进程、同一 provider、同一模型） |
| 模型 | deepseek/deepseek-v4.1-flash |
| 差异变量 | `@xia-sc/dsh-language-policy` 是否启用（唯一差异） |
| 题目 | `tools/experiment-prompt.md`，六个样本逐字相同（Windows + nvm-windows 升级排障，纯分析、不调工具） |
| 会话 | 每次一个独立 subagent（独立 session、独立系统提示词快照） |
| 样本量 | 每组 3 次 |
| 统计口径 | reasoning 块中 CJK 字符 / (CJK 字符 + 英文单词数)，累加该会话全部 reasoning 块 |

两组的系统提示词实测（同一 Host，同一 agent 类型）：

| 组 | 系统提示词长度 | 含策略 | AGENTS.md 基线 |
|---|---|---|---|
| A（仅 AGENTS.md） | 5932 字符 | 否 | 有（555 字符，含「内部推理一律使用中文」） |
| B（插件） | 6121 字符 | 是 | 有（同上） |

6121 − 5932 = 189 = 策略文本 187 字符 + 段落分隔符 2 字符，两组唯一的提示词差异就是这段策略。

## 结果

| 样本 | reasoning 字符 | CJK 字符 | 英文词 | 中文占比 |
|---|---|---|---|---|
| A1 | 28,546 | 8,329 | 2,187 | **79.2%** |
| A2 | 31,593 | 7,622 | 2,640 | **74.3%** |
| A3 | 32,092 | 3,871 | 4,003 | **49.2%** |
| B1 | 29,216 | 8,256 | 2,383 | **77.6%** |
| B2 | 37,892 | 10,344 | 2,986 | **77.6%** |
| B3 | 25,938 | 6,793 | 2,111 | **76.3%** |

汇总：

| 组 | 逐样本均值 | 中位数 | 极差 | 标准差 | 合并口径（CJK 总和 / 总字符+词） |
|---|---|---|---|---|---|
| A 仅 AGENTS.md | 67.5% | 74.3% | 30.0pp | 16.1pp | 19,822 / 28,652 = **69.2%** |
| B 插件 | 77.2% | 77.6% | 1.3pp | 0.75pp | 25,393 / 32,873 = **77.2%** |

## 观察

1. **均值**：插件组逐样本均值高 9.6pp；合并口径高 7.9pp。
2. **稳定性差异远大于均值差异**：基线组标准差 16.1pp、极差 30pp；插件组标准差 0.75pp、极差 1.3pp。
3. 基线组 A3 是典型的「长推理英文漂移」：32k 字符推理里 CJK 与英文词几乎 1:1（49.2%），与计划 1.2 节调查到的排障会话 4% / 9% 属同一类现象，只是本轮漂移程度较轻（对半）。
4. 插件组三次都落在 76–78% 的窄带内，没有出现漂移样本。
5. 三次基线样本中有两次（79.2%、74.3%）与插件组接近——说明 AGENTS.md 本身有效，插件补的是**尾部风险**：它把「偶尔掉到 50% 以下」的长尾压掉。

## 结论

在本实验条件下：

- 只靠 AGENTS.md 时，中文推理占比均值约 67–69%，且存在一次近半英文的漂移（49.2%）；
- 加上插件后，中文推理占比稳定在 76–78%，三次样本几乎无波动；
- 因此插件的价值不只是抬高均值，更是**降低漂移概率与方差**。

局限：n=3/组、单模型、单题、单宿主，不足以给统计显著性结论；provider 不提供 seed/温度控制，抽样有随机性。这不是「100% 中文思考」的保证。

## 实验操作记录

1. `plugin_manager set_bundle @xia-sc/dsh-language-policy enabled=false`（applied，即时生效）；
2. 跑 A 组 3 个 subagent，逐个用 `tools/check-agent-log.mjs` 确认系统提示词 `hasPolicy: false`、长度 5932；
3. `set_bundle enabled=true`（applied）；
4. 跑 B 组 3 个 subagent，确认 `hasPolicy: true`、长度 6121；
5. `tools/reasoning-stats.mjs` 统计，插件保持启用状态（实验后已恢复）。
